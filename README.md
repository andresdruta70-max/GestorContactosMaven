# Gestor de Contactos (Java + MySQL + Maven)

Aplicación de consola interactiva desarrollada en Java con arquitectura CRUD completa conectada a una base de datos MySQL mediante JDBC.

## 🚀 Funcionalidades
- **Listar contactos:** Muestra todos los registros de la base de datos.
- **Añadir contacto:** Permite registrar un nuevo contacto (Nombre, Teléfono, Email).
- **Editar contacto:** Modifica los datos de un contacto existente por su ID.
- **Eliminar contacto:** Borra un registro específico por su ID.

## 🛠️ Tecnologías utilizadas
- Java
- MySQL Server
- Maven
- MySQL Connector/J (JDBC)
